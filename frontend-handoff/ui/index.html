    Add from a notebook, then start

    curl -s -X POST http://HOST:8385/api/jobs \
     -H 'Content-Type: application/json' \
     -H 'X-Fishy-Token: <token>' \
     -d '{"name":"pellet-01","kind":"sample",
          "params":{"scans":10,"resolution":4}}'

    Python

    import requests
s = requests.Session()
s.headers["X-Fishy-Token"] = "<token>"
job = s.post("http://HOST:8385/api/jobs", json={
    "name": "pellet-01", "kind": "sample",
    "params": {"scans": 10, "resolution": 4,
               "start": 400, "end": 4000},
    "start_now": False,
}).json()["job"]
s.post(f"http://HOST:8385/api/jobs/{job['id']}/start")
# 409 {"busy": true, "current": "<id>"} while another job runs
